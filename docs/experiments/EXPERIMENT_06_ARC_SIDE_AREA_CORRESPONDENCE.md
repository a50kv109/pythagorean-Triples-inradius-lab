## 1. Постановка задачи и стандартная геометрическая нотация

Рассматривается невырожденный прямоугольный треугольник $\triangle OAB$ с вписанной окружностью $K_i$ радиуса $r > 0$ и инцентром $I = (r, r)$.  
В ходе математического аудита (`EXPERIMENT_06_MATHEMATICAL_AUDIT.md`) была устранена неоднозначность между координатной индексацией катетов из `Experiments 01–05` ($OA$ на оси $+Oy$, $OB$ на оси $+Ox$) и классической противоположной нотацией:

- **Стандартная нотация `Experiment 06`:**
  - $\angle A = 90^\circ - \alpha$ (при вершине $A = (0, |OA|)$), **противолежащая сторона** $a = |OB|$ (`legOB`), малый треугольник $\triangle IOB$ с площадью $S_a = \frac{1}{2}ar$;
  - $\angle B = \alpha$ (при вершине $B = (|OB|, 0)$), **противолежащая сторона** $b = |OA|$ (`legOA`), малый треугольник $\triangle IOA$ с площадью $S_b = \frac{1}{2}br$;
  - $\angle C = 90^\circ$ (при вершине $O = (0, 0)$), **противолежащая сторона** $c = |AB|$, малый треугольник $\triangle IAB$ с площадью $S_c = \frac{1}{2}cr$.
- **Связь с координатной системой `Experiments 01–05` (без изменения кода `Exp. 01–05`):**
  $$a_{\text{std}} = |OB| = b_{\text{coord}}, \qquad b_{\text{std}} = |OA| = a_{\text{coord}}, \qquad c_{\text{std}} = c_{\text{coord}}.$$
  Таким образом, при $\alpha = 30^\circ$ ($\angle A = 60^\circ > \angle B = 30^\circ$) выполняется стандартное неравенство $a = 4.7321 > b = 2.7321$ (при $r = 1$).

### Определения трёх систем распределения

1. **Система A (Угловая система дуг $K_i$):** порождается радиусами касания $IT_{OA}, IT_{OB}, IT_{AB}$.  
   Центральные углы: $\varphi_A = 180^\circ - A = 90^\circ + \alpha$, $\varphi_B = 180^\circ - B = 180^\circ - \alpha$, $\varphi_C = 90^\circ$;  
   длины дуг $L_K = r\varphi_K$; нормализованные доли $w^{\text{arc}}_K = \frac{L_K}{2\pi r} = \frac{\varphi_K}{360^\circ}$ ($K \in \{A, B, C\}$).
2. **Система B (Линейная система сторон и касательных отрезков):** стороны $a, b, c$, периметр $P = a + b + c = 2p$, касательные отрезки $t_A = p - a$, $t_B = p - b$, $t_C = p - c = r$; доли $w^{\text{side}}_k = \frac{s_k}{P}$ ($k \in \{a, b, c\}$).
3. **Система C (Площадная система разбиения треугольника):** порождается отрезками к вершинам $IO, IA, IB$ (биссектрисами), делящими $\triangle OAB$ на $\triangle IOB, \triangle IOA, \triangle IAB$ с площадями $S_a, S_b, S_c$ (в сумме $S = pr$) и долями $w^{\text{area}}_k = \frac{S_k}{S}$.

## 2. Пошаговые математические выводы (L-01 — L-08)

### L-01. Изоморфизм долей Системы B и Системы C *(Категория A)*
Все три малых треугольника имеют одну и ту же высоту $r$ (радиус касания перпендикулярен основанию):
$$S_a = \frac{1}{2}ar, \quad S_b = \frac{1}{2}br, \quad S_c = \frac{1}{2}cr, \quad S = \frac{1}{2}Pr \implies \boxed{w^{\text{area}}_k = \frac{S_k}{S} = \frac{s_k}{P} = w^{\text{side}}_k \quad (k \in \{a,b,c\}).}$$

### L-02. Закон углового распределения Системы A *(Категория A)*
$$\boxed{\varphi_A = 180^\circ - A = 90^\circ + \alpha, \qquad \varphi_B = 180^\circ - B = 180^\circ - \alpha, \qquad \varphi_C = 90^\circ,}$$
$$w^{\text{arc}}_A = \frac{1}{4} + \frac{\alpha^\circ}{360^\circ}, \qquad w^{\text{arc}}_B = \frac{1}{2} - \frac{\alpha^\circ}{360^\circ}, \qquad w^{\text{arc}}_C \equiv \frac{1}{4} = 25\%.$$

### L-03. Прямой синусный перенос от дуг к сторонам и площадям *(Категория B)*
В стандартной нотации $a = c\sin A$, $b = c\sin B$, $c = c\sin C$. Поскольку $\sin(180^\circ - X) = \sin X = \sin\varphi_X$, индексы согласованы **напрямую, без перестановки**:
$$\boxed{w^{\text{area}}_a : w^{\text{area}}_b : w^{\text{area}}_c = \sin\varphi_A : \sin\varphi_B : \sin\varphi_C, \qquad w^{\text{area}}_k = \frac{\sin\varphi_K}{\sin\varphi_A + \sin\varphi_B + \sin\varphi_C}.}$$

### L-04. Половинное тангенсное разложение через углы дуг *(Категория B)*
Касательные отрезки при вершинах равны $t_A = p - a = r\cot\frac{A}{2} = r\tan\frac{\varphi_A}{2}$, $t_B = p - b = r\cot\frac{B}{2} = r\tan\frac{\varphi_B}{2}$, $t_C = r$. Так как $a = t_B + r$, $b = t_A + r$, $c = t_A + t_B$:
$$\boxed{a = r\left(1 + \tan\frac{\varphi_B}{2}\right), \qquad b = r\left(1 + \tan\frac{\varphi_A}{2}\right), \qquad c = r\left(\tan\frac{\varphi_A}{2} + \tan\frac{\varphi_B}{2}\right),}$$
$$\boxed{\left(\tan\frac{\varphi_A}{2} - 1\right)\left(\tan\frac{\varphi_B}{2} - 1\right) = 2, \qquad \frac{S}{r^2} = \frac{p}{r} = \tan\frac{\varphi_A}{2}\tan\frac{\varphi_B}{2}.}$$

### L-05. Пифагорово соотношение площадей малых треугольников *(Категория C)*
$$\boxed{S_a^2 + S_b^2 = S_c^2, \qquad (w^{\text{area}}_a)^2 + (w^{\text{area}}_b)^2 = (w^{\text{area}}_c)^2.}$$

### L-06. Закон площадного дефекта и квадрата радиуса $r^2$ *(Категория C)*
Из $a + b - c = 2r$ и $S_k = \frac{1}{2} s_k r$:
$$\boxed{S_a + S_b - S_c = r^2, \qquad w^{\text{area}}_a + w^{\text{area}}_b - w^{\text{area}}_c = 2w^{\text{area}}_a w^{\text{area}}_b = \frac{r^2}{S}, \qquad w^{\text{area}}_c = \frac{1}{2} - \frac{r^2}{2S}.}$$
Максимум дефекта достигается при $\alpha = 45^\circ$: $\max \frac{r^2}{S} = 3 - 2\sqrt{2} \approx 17.1573\%$, откуда $\min w^{\text{area}}_c = \sqrt{2} - 1 \approx 41.4214\%$.

### L-07. Неэквивалентность систем долей и полная структура 6 пересечений *(Категория C)*
- **Невозможность одновременного равенства трёх долей:** $w^{\text{arc}}_C \equiv 25\% < \sqrt{2} - 1 \le w^{\text{area}}_c < 50\%$ для всех $\alpha \in (0^\circ, 90^\circ)$ — дуга при прямом угле всегда строго наименьшая, тогда как площадь при гипотенузе всегда строго наибольшая.
- **Строгие непересекающиеся пары:** $w^{\text{arc}}_A(\alpha) > w^{\text{area}}_b(\alpha)$ и $w^{\text{arc}}_B(\alpha) > w^{\text{area}}_a(\alpha)$ всюду на $(0^\circ, 90^\circ)$.
- **Все 6 точечных совпадений долей (найдены бисекцией и проверены 8999-точечным сканированием):**
  1. Одноимённое $w^{\text{arc}}_A = w^{\text{area}}_a$ при $\alpha \approx 34.356155^\circ$ (доля $34.5434\%$);
  2. Одноимённое $w^{\text{arc}}_B = w^{\text{area}}_b$ при $\alpha \approx 55.643845^\circ$ (доля $34.5434\%$);
  3. Перекрёстное $w^{\text{arc}}_B = w^{\text{area}}_c$ при $\alpha \approx 25.930202^\circ$ (доля $42.7972\%$);
  4. Перекрёстное $w^{\text{arc}}_A = w^{\text{area}}_c$ при $\alpha \approx 64.069798^\circ$ (доля $42.7972\%$);
  5. Перекрёстное $w^{\text{arc}}_C = w^{\text{area}}_b = \frac{1}{4}$ при $\alpha = \arctan(3/4) \approx 36.869898^\circ$ — **ровно в треугольнике $(3,4,5)$** ($a=4, b=3, c=5$);
  6. Перекрёстное $w^{\text{arc}}_C = w^{\text{area}}_a = \frac{1}{4}$ при $\alpha = \arctan(4/3) \approx 53.130102^\circ$ — **ровно в треугольнике $(4,3,5)$** ($a=3, b=4, c=5$).

### L-08. Различие радиусов касания ($\varphi_X$) и отрезков к вершинам ($\psi_X$) *(Категория A)*
$$\boxed{\psi_A = \angle BIO = 90^\circ + \frac{A}{2}, \quad \psi_B = \angle AIO = 90^\circ + \frac{B}{2}, \quad \psi_C = \angle AIB \equiv 135^\circ \ne 90^\circ = \varphi_C, \quad S_c = \frac{|IA|\,|IB|}{2\sqrt{2}}.}$$

### Теорема восстановления из углового распределения дуг (реализована в `reconstructNormalizedModelFromArcShares`)
Зная **только** тройку нормализованных долей дуг $(w^{\text{arc}}_A, w^{\text{arc}}_B, w^{\text{arc}}_C)$ любого невырожденного треугольника ($w^{\text{arc}}_K \in (0, 0.5)$, $\sum w^{\text{arc}}_K = 1$), все внутренние углы, отношения сторон, доли площадей и безразмерный дефект $r^2/S$ однозначно восстанавливаются без измерения сторон:
$$\varphi_K = 2\pi w^{\text{arc}}_K, \quad \angle K = \pi(1 - 2w^{\text{arc}}_K), \quad w^{\text{side}}_k = w^{\text{area}}_k = \frac{\sin(2\pi w^{\text{arc}}_K)}{\sum_{J\in\{A,B,C\}} \sin(2\pi w^{\text{arc}}_J)}, \quad \frac{r^2}{S} = \frac{1}{\sum_{K}\tan(\pi w^{\text{arc}}_K)}.$$

## 3. Классификационный каталог (Категории A–E)

- **Категория A (известные закономерности):** `L-01`, `L-02`, `L-08`.
- **Категория B (новые представления известных законов):** `L-03` (прямой синусный оператор переноса), `L-04` (гиперболический тангенсный инвариант).
- **Категория C (новые следствия известных теорем):** `L-05` (пифагорово соотношение малых площадей), `L-06` (дефект площади $r^2$), `L-07` (инверсия порядка $C/c$ и 6 точечных пересечений долей).
- **Категория D:** пусто (мы не приписываем классическим результатам искусственную новизну).
- **Категория E (опровергнутые гипотезы):** одновременная пропорциональность долей дуг и площадей ($w^{\text{arc}}_K \equiv w^{\text{area}}_k$), тождественность $\psi_X = \varphi_X$, а также гипотеза об отсутствии одноимённых пересечений при стандартной нотации (исправлено аудитом).
