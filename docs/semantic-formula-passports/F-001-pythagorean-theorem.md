# F-001 — Теорема Пифагора (`Pythagorean Theorem`)

## 1. Formula ID
`F-001` *(соотносится с `PTH-001` в UMFP Insight Bank и `PCL-A03` в Pythagoras-Circles-Lab)*

## 2. Formula Name
Теорема Пифагора для прямоугольного треугольника (`Pythagorean Theorem`)

## 3. Canonical Expression
$$c^2 = a^2 + b^2$$
Эквивалентная разрешённая форма относительно гипотенузы (при $c > 0$):
$$c = \sqrt{a^2 + b^2}$$

## 4. Semantic Statement
В любом прямоугольном треугольнике на евклидовой плоскости квадрат длины стороны, лежащей напротив прямого угла (гипотенузы), равен сумме квадратов длин двух сторон, образующих прямой угол (катетов).

## 5. Symbol Registry
| Символ | Значение | Математическая роль | Происхождение / как возникает | Область значений |
|---|---|---|---|---|
| $a$ | Длина первого катета | Независимый параметр (длина отрезка) | Одна из двух сторон, прилежащих к прямому углу $\angle C = 90^\circ$ | $a \in \mathbb{R}_{>0}$ |
| $b$ | Длина второго катета | Независимый параметр (длина отрезка) | Вторая сторона, прилежащая к прямому углу $\angle C = 90^\circ$ | $b \in \mathbb{R}_{>0}$ |
| $c$ | Длина гипотенузы | Зависимая сторона | Сторона, лежащая строго напротив прямого угла $\angle C = 90^\circ$ | $c > \max(a, b) > 0$ |

## 6. Definitions
- **Прямоугольный треугольник:** невырожденный треугольник на евклидовой плоскости, один из внутренних углов которого равен $90^\circ$ ($\pi/2$ рад).
- **Катеты ($a, b$):** две стороны прямоугольного треугольника, образующие прямой угол; они взаимно перпендикулярны.
- **Гипотенуза ($c$):** самая длинная сторона прямоугольного треугольника, соединяющая свободные концы катетов и противолежащая прямому углу.
- **Площадь квадрата со стороной $x$:** $S(x) = x^2$.

## 7. Geometric Interpretation
Если на каждом из двух катетов $a$ и $b$ и на гипотенузе $c$ построить вовне (или вообще на плоскости) квадраты со сторонами $a$, $b$ и $c$, то их площади будут равны $a^2$, $b^2$ и $c^2$. Теорема утверждает геометрическую равносоставленность и аддитивность площадей: суммарная площадь двух квадратов на катетах точно равна площади квадрата на гипотенузе.

## 8. Preconditions
1. Треугольник лежит в плоской **евклидовой** геометрии (кривизна равна нулю, сумма углов равна $180^\circ$).
2. Угол между сторонами $a$ и $b$ строго равен $90^\circ$.
3. Треугольник невырожден: $a > 0$, $b > 0$, $c > 0$.
4. Векторно-метрическое расстояние задано стандартной евклидовой нормой.

## 9. Domain and Constraints
- **Область определения:** $(a, b) \in (0, +\infty) \times (0, +\infty) \subset \mathbb{R}^2$.
- **Ограничения `UMFP Core 0.1.x`:** для записи `a^2 + b^2 = c^2` синтаксических ограничений нет; для записи `c = \sqrt{a^2 + b^2}` в вещественной области требуется $a^2 + b^2 \ge 0$ (выполняется автоматически для $a, b \in \mathbb{R}$).
- **Классификация `UMFP 0.1.x`:** распознаётся через правило `known_identity` как домен `GEOMETRY` (`logicalOrganizations: ["EQUATION_RELATION", "POWER_DEPENDENCE"]`).

## 10. Derivation
Приведём классическое геометрическое доказательство методом разбиения квадрата (без пропущенных шагов):

1. Построим квадрат со стороной $a + b$. Площадь всего этого квадрата равна:
   $$S_{\text{полн}} = (a + b)^2 = a^2 + 2ab + b^2.$$
2. Разделим каждую из четырёх сторон большого квадрата на два отрезка длиной $a$ и $b$ в одном циклическом порядке (по часовой стрелке) и соединим соседние точки деления отрезками.
3. По углам большого квадрата образуются **четыре прямоугольных треугольника** с катетами $a$ и $b$ и прямыми углами в вершинах большого квадрата.
4. По первому признаку равенства треугольников (две стороны $a, b$ и прямой угол между ними) все четыре треугольника равны друг другу, поэтому у каждого из них гипотенуза имеет одну и ту же длину $c$, а острые углы равны $\alpha$ и $\beta$, где $\alpha + \beta = 90^\circ$.
5. В центре остаётся четырёхугольник, все четыре стороны которого равны $c$. Каждый его внутренний угол смежен с парой острых углов $\alpha$ и $\beta$ на прямой стороне большого квадрата:
   $$\gamma = 180^\circ - (\alpha + \beta) = 180^\circ - 90^\circ = 90^\circ.$$
   Следовательно, центральный четырёхугольник — **квадрат со стороной $c$**, а его площадь равна $c^2$.
6. Площадь каждого из четырёх прямоугольных треугольников равна $\frac{ab}{2}$ (см. паспорт [`F-002`](F-002-right-triangle-area.md)). По свойству аддитивности площади:
   $$S_{\text{полн}} = 4 \cdot \frac{ab}{2} + c^2 = 2ab + c^2.$$
7. Приравниваем два выражения для одной и той же площади большого квадрата:
   $$a^2 + 2ab + b^2 = 2ab + c^2.$$
8. Вычитаем $2ab$ из обеих частей равенства и получаем:
   $$\boxed{a^2 + b^2 = c^2}.$$

## 13. Numerical Example
Контрольный прямоугольный треугольник $5\text{–}12\text{–}13$:
- Дано: $a = 5$, $b = 12$, $c = 13$.
- Левая часть: $a^2 + b^2 = 5^2 + 12^2 = 25 + 144 = 169$.
- Правая часть: $c^2 = 13^2 = 169$.
- Итог: $169 = 169$, $c = \sqrt{169} = 13$.

## 14. Validation Cases
1. Классическая египетская тройка $(3, 4, 5)$: $3^2 + 4^2 = 9 + 16 = 25 = 5^2$.
2. Контрольная тройка $(5, 12, 13)$: $5^2 + 12^2 = 169 = 13^2$.
3. Равнобедренный прямоугольный треугольник $(4, 4, 4\sqrt{2})$: $4^2 + 4^2 = 32 = (4\sqrt{2})^2$.
4. Вырожденный предел ($a \to 0^+$): при $a = 0$ треугольник исчезает, хотя алгебраически $0^2 + b^2 = b^2$.

## 15. Common Misinterpretations
1. **Применение к непрямоугольному треугольнику:** при $\gamma \neq 90^\circ$ равенство $c^2 = a^2 + b^2$ ложно; действует теорема косинусов $c^2 = a^2 + b^2 - 2ab\cos\gamma$.
2. **Путаница обозначений:** формула верна только если $c$ — **гипотенуза** (сторона напротив $90^\circ$), а не произвольная третья сторона.
3. **Неевклидова геометрия:** на сфере или плоскости Лобачевского $a^2 + b^2 = c^2$ не выполняется.
