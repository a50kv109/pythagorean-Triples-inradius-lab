# F-006 — Четыре окружности, связанные с прямоугольным треугольником (`Four-Circles Identity`)

## 1. Formula ID
`F-006` *(соотносится с `PTH-003` и `PTH-004` в UMFP Insight Bank и с `PCL-C10`, `PCL-D15`, `PCL-E16`, `PCL-G28` в Pythagoras-Circles-Lab)*

## 2. Formula Name
Площади четырёх окружностей прямоугольного треугольника и аддитивное тождество их квадратных корней (`Four-Circles Area-Root Identity`)

## 3. Canonical Expression
**Определения площадей четырёх окружностей:**
$$K_a = \frac{\pi a^2}{4}, \qquad K_b = \frac{\pi b^2}{4}, \qquad K_c = \frac{\pi c^2}{4}, \qquad K_i = \pi r^2.$$
**Центральное тождество квадратных корней из площадей:**
$$\sqrt{K_a} + \sqrt{K_b} = \sqrt{K_c} + \sqrt{K_i}.$$

## 4. Semantic Statement
Если на катетах и гипотенузе прямоугольного треугольника построить квадраты и вписать в них окружности с площадями $K_a, K_b, K_c$, а четвёртую окружность с площадью $K_i$ вписать внутрь самого треугольника, то сумма квадратных корней из площадей окружностей на катетах равна сумме квадратных корней из площадей окружности на гипотенузе и вписанной окружности треугольника. Это тождество не является новой независимой теоремой: при извлечении корней оно алгебраически эквивалентно линейному соотношению $a + b = c + 2r$ из паспорта [`F-005`](F-005-right-triangle-inradius.md).

## 6. Definitions
- **Окружность $K_a$:** окружность, вписанная в внешний квадрат $Q_a$ на катете $a$; диаметр равен $a$, радиус $R_a = a/2$, центр $O_a = (-a/2, a/2)$.
- **Окружность $K_b$:** окружность, вписанная в внешний квадрат $Q_b$ на катете $b$; диаметр равен $b$, радиус $R_b = b/2$, центр $O_b = (b/2, -b/2)$.
- **Окружность $K_c$:** окружность, вписанная в внешний квадрат $Q_c$ на гипотенузе $c$; диаметр равен $c$, радиус $R_c = c/2$, центр $O_c = \big(\frac{a+b}{2}, \frac{a+b}{2}\big)$.
- **Окружность $K_i$:** обычная вписанная окружность треугольника $\triangle OAB$; радиус $r$, диаметр $2r$, центр $I = (r, r)$.
- **Пятая окружность (описанная окружность Фалеса $K_o$):** окружность, проходящая через все три вершины $O, A, B$ с диаметром на гипотенузе $AB$, радиусом $R_o = c/2$ и центром $O_o = \frac{A+B}{2} = \big(\frac{b}{2}, \frac{a}{2}\big)$. Имеет **равную площадь** $K_o = \frac{\pi c^2}{4} = K_c$, но **другой центр** ($|O_o - O_c| = \frac{c}{2} > 0$) и другое геометрическое положение (охватывает треугольник, а не лежит в квадрате $Q_c$).

## 7. Geometric Interpretation
У трёх квадратных окружностей $K_a, K_b, K_c$ сами **площади** складываются по закону Пифагора:
$$K_a + K_b = \frac{\pi}{4}(a^2 + b^2) = \frac{\pi}{4}c^2 = K_c.$$
Поэтому добавить к правой части площадь $K_i > 0$ нельзя: $K_a + K_b - (K_c + K_i) = -K_i < 0$.  
Однако операция $\sqrt{\cdot}$ переводит квадратичную величину (площадь) обратно в **линейную** величину (длину диаметра или удвоенного радиуса с множителем $\frac{\sqrt{\pi}}{2}$). После этого линейное условие касания $a + b = c + 2r$ превращается в точное равенство корней из площадей.

## 8. Preconditions
1. Исходный треугольник — невырожденный прямоугольный треугольник в евклидовой плоскости ($a^2 + b^2 = c^2$, $a, b > 0$).
2. Символы $K_a, K_b, K_c, K_i$ обозначают именно площади четырёх указанных окружностей (а не произвольные числа).
3. Под $\sqrt{\cdot}$ берутся главные арифметические (неотрицательные) квадратные корни.

## 9. Domain and Constraints
- **Область определения:** $(a, b) \in (0, +\infty)^2$.
- **Поведение `UMFP Core 0.1.x`:** для записи `\sqrt{K_c} + \sqrt{K_i} = \sqrt{K_a} + \sqrt{K_b}` Core формирует алгебраический паспорт (`RADICAL: 4`, `EQUATION_RELATION`, `RADICAL_DEPENDENCE`, `domains: ["ALGEBRA"]`, ограничения `K_a, K_b, K_c, K_i >= 0`), тогда как геометрическая расшифровка содержится именно в Insight Bank (`PTH-004`) и настоящем семантическом паспорте.

## 10. Derivation
1. Из формулы площади круга $S_{\text{круга}} = \pi R^2$ и определений радиусов $R_a = \frac{a}{2}$, $R_b = \frac{b}{2}$, $R_c = \frac{c}{2}$, $R_i = r$ получаем площади четырёх кругов:
   $$K_a = \pi \left(\frac{a}{2}\right)^2 = \frac{\pi a^2}{4}, \qquad K_b = \pi \left(\frac{b}{2}\right)^2 = \frac{\pi b^2}{4}, \qquad K_c = \pi \left(\frac{c}{2}\right)^2 = \frac{\pi c^2}{4}, \qquad K_i = \pi r^2.$$
2. Извлекаем главные квадратные корни, учитывая положительность $\pi > 0$ и длин $a, b, c, r > 0$ ($\sqrt{x^2} = x$ при $x > 0$):
   $$\sqrt{K_a} = \sqrt{\frac{\pi a^2}{4}} = \frac{\sqrt{\pi}}{2}\,a, \qquad \sqrt{K_b} = \frac{\sqrt{\pi}}{2}\,b, \qquad \sqrt{K_c} = \frac{\sqrt{\pi}}{2}\,c, \qquad \sqrt{K_i} = \sqrt{\pi}\,r = \frac{\sqrt{\pi}}{2}\cdot (2r).$$
3. Сложим корни из площадей окружностей на катетах (левая часть):
   $$\sqrt{K_a} + \sqrt{K_b} = \frac{\sqrt{\pi}}{2}(a + b).$$
4. Сложим корни из площадей окружности на гипотенузе и вписанной окружности (правая часть):
   $$\sqrt{K_c} + \sqrt{K_i} = \frac{\sqrt{\pi}}{2}c + \frac{\sqrt{\pi}}{2}(2r) = \frac{\sqrt{\pi}}{2}(c + 2r).$$
5. По паспорту [`F-005`](F-005-right-triangle-inradius.md) для любого прямоугольного треугольника выполняется $r = \frac{a + b - c}{2}$, что после умножения на $2$ и переноса $c$ даёт линейное тождество:
   $$2r = a + b - c \iff a + b = c + 2r.$$
6. Подставляя $c + 2r = a + b$ в выражение шага 4, получаем:
   $$\sqrt{K_c} + \sqrt{K_i} = \frac{\sqrt{\pi}}{2}(a + b) = \sqrt{K_a} + \sqrt{K_b}.$$
7. Следовательно:
   $$\boxed{\sqrt{K_a} + \sqrt{K_b} = \sqrt{K_c} + \sqrt{K_i}}.$$

**Эквивалентность и статус:** разделив обе части тождества на положительную константу $\frac{\sqrt{\pi}}{2}$, мы возвращаемся к $a + b = c + 2r \iff r = \frac{a+b-c}{2}$. Значит, формула является эквивалентной геометрической переформулировкой `F-005` в терминах площадей четырёх кругов, а не независимой новой теоремой.

## 11. Dependency Graph
- **Опирается на:** определения четырёх окружностей ($K_a, K_b, K_c, K_i$), формулу площади круга $\pi R^2$, линейную формулу вписанного радиуса [`F-005`](F-005-right-triangle-inradius.md) (и через неё — на `F-001`, `F-002`, `F-003`, `F-004`).
- **Связь с пятым кругом:** при замене $K_c$ на площадь описанной окружности Фалеса $K_o$ числовое равенство $\sqrt{K_a}+\sqrt{K_b}=\sqrt{K_o}+\sqrt{K_i}$ также сохраняется, так как $K_o = K_c = \frac{\pi c^2}{4}$ (при различных центрах $O_o \neq O_c$).

## 12. Mathematical Status
- **Статус достоверности:** `DERIVED` (строго выведенное следствие; переформулировка `F-005` через квадратные корни площадей четырёх кругов). Не является самостоятельным открытием или новой теоремой.

## 13. Numerical Example
Контрольный прямоугольный треугольник $5\text{–}12\text{–}13$ ($a = 5, b = 12, c = 13, r = 2$):
1. Точные площади:
   $$K_a = \frac{\pi \cdot 5^2}{4} = \frac{25\pi}{4}, \qquad K_b = \frac{\pi \cdot 12^2}{4} = 36\pi, \qquad K_c = \frac{\pi \cdot 13^2}{4} = \frac{169\pi}{4}, \qquad K_i = \pi \cdot 2^2 = 4\pi.$$
2. Проверка пифагоровой суммы квадратных кругов:
   $$K_a + K_b = \frac{25\pi}{4} + \frac{144\pi}{4} = \frac{169\pi}{4} = K_c.$$
3. Проверка контраста прямых площадей:
   $$K_a + K_b - (K_c + K_i) = -4\pi = -K_i < 0.$$
4. Точная проверка корней из площадей:
   $$\sqrt{K_a} = \frac{5\sqrt{\pi}}{2}, \qquad \sqrt{K_b} = 6\sqrt{\pi}, \qquad \sqrt{K_c} = \frac{13\sqrt{\pi}}{2}, \qquad \sqrt{K_i} = 2\sqrt{\pi}.$$
   - Левая часть: $\sqrt{K_a} + \sqrt{K_b} = \left(\frac{5}{2} + 6\right)\sqrt{\pi} = \frac{17\sqrt{\pi}}{2}$.
   - Правая часть: $\sqrt{K_c} + \sqrt{K_i} = \left(\frac{13}{2} + 2\right)\sqrt{\pi} = \frac{17\sqrt{\pi}}{2}$.
   - Совпадение точное: $\frac{17\sqrt{\pi}}{2} = \frac{17\sqrt{\pi}}{2}$ ($\approx 15.065848$ в числах).

## 14. Validation Cases
1. $(3, 4, 5)$, $r = 1$: $\frac{3\sqrt{\pi}}{2} + 2\sqrt{\pi} = \frac{7\sqrt{\pi}}{2} = \frac{5\sqrt{\pi}}{2} + \sqrt{\pi}$.
2. $(5, 12, 13)$, $r = 2$: $\frac{5\sqrt{\pi}}{2} + 6\sqrt{\pi} = \frac{17\sqrt{\pi}}{2} = \frac{13\sqrt{\pi}}{2} + 2\sqrt{\pi}$.
3. $(4, 4, 4\sqrt{2})$, $r = 4 - 2\sqrt{2}$: $2\sqrt{\pi} + 2\sqrt{\pi} = 4\sqrt{\pi} = 2\sqrt{2\pi} + (4-2\sqrt{2})\sqrt{\pi}$.
4. Отказ на непрямоугольном треугольнике $(5, 5, 6)$ ($r = 1.5$): $\sqrt{K_a}+\sqrt{K_b} = 5\sqrt{\pi}$, а $\sqrt{K_c}+\sqrt{K_i} = 4.5\sqrt{\pi} \neq 5\sqrt{\pi}$.

## 15. Common Misinterpretations
1. **Отождествление корней площадей с самими площадями:** равенство $K_a + K_b = K_c + K_i$ неверно (отличается на $-K_i$).
2. **Отождествление круга $K_c$ и окружности Фалеса $K_o$:** хотя $K_c = K_o = \frac{\pi c^2}{4}$, их центры различны ($O_c = (\frac{a+b}{2}, \frac{a+b}{2})$, $O_o = (\frac{b}{2}, \frac{a}{2})$) и только $K_o$ проходит через вершины $O, A, B$.
3. **Заявление о «новой общей теореме для всех треугольников»:** формула верна только для евклидовых прямоугольных треугольников и полностью эквивалентна $r = \frac{a+b-c}{2}$.
