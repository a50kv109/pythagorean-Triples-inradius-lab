# F-003 — Полупериметр треугольника (`Semiperimeter of a Triangle`)

## 1. Formula ID
`F-003` *(вспомогательное определение; в `Pythagoras-Circles-Lab` периметр $P = a + b + c$ зафиксирован в `PCL-A04`)*

## 2. Formula Name
Полупериметр треугольника (`Semiperimeter Definition`)

## 3. Canonical Expression
$$p = \frac{a + b + c}{2}$$
*(Примечание: в русскоязычной литературе полупериметр обычно обозначается $p$, а периметр — $P$; в англоязычной литературе полупериметр часто обозначается $s$ от англ. semiperimeter. Чтобы исключить путаницу с площадью $S$, в настоящем наборе паспортов принято $S$ — площадь, $P$ — периметр, $p$ — полупериметр.)*

## 4. Semantic Statement
Полупериметр треугольника $p$ по определению равен половине его периметра $P$, то есть половине суммы длин всех трёх сторон треугольника. Это введённое сокращённое обозначение величины, а не самостоятельная теорема.

## 6. Definitions
- **Периметр ($P$):** сумма длин всех сторон многоугольника; для треугольника со сторонами $a, b, c$:
  $$P = a + b + c.$$
- **Полупериметр ($p$):** половина периметра фигуры:
  $$p \stackrel{\text{def}}{=} \frac{P}{2} = \frac{a + b + c}{2}.$$
  Иначе говоря, $2p = a + b + c = P$.

## 7. Geometric Interpretation
Если развернуть три стороны треугольника $a, b, c$ вдоль одной прямой в единый отрезок длиной $P = a + b + c$ (полный периметр), то середина этого развёрнутого отрезка делит его на две равные части длиной $p = \frac{a+b+c}{2}$. В геометрии вписанной окружности полупериметр дополнительно равен сумме трёх различных касательных отрезков от вершин треугольника до точек касания, а также длине отрезка касательной от вершины до точки касания вневписанной окружности.

## 8. Preconditions
1. $a, b, c > 0$ — длины сторон треугольника.
2. Для существования невырожденного треугольника должны выполняться строгие неравенства треугольника:
   $$a + b > c, \qquad a + c > b, \qquad b + c > a.$$
   *(Эквивалентно в терминах полупериметра: $p > a$, $p > b$, $p > c$.)*

## 9. Domain and Constraints
- **Область определения:** $(a, b, c) \in \mathbb{R}_{>0}^3$ (с геометрическим ограничением неравенства треугольника).
- **Синтаксические ограничения `UMFP Core 0.1.x`:** для `\frac{a + b + c}{2}` фиксируются `FRACTION: 1`, `freeVariables: ["a", "b", "c", "p"]`, `domains: ["ALGEBRA"]` и `2 != 0 [required]`.
- **Принцип Semantic Closure:** символ $p$ **запрещено** использовать в последующих формулах (`S = pr`, формула Герона и т.п.) без явной ссылки на определение `p = (a + b + c) / 2`.

## 10. Derivation
Формула $p = \frac{a + b + c}{2}$ **не доказывается как теорема**, так как является **определением** нового обозначения $p$. Последовательность её введения такова:

1. Для треугольника с длинами сторон $a, b, c$ определяется его полный периметр — сумма длин сторон:
   $$P = a + b + c.$$
2. Во многих геометрических формулах (прежде всего в формуле площади через вписанный радиус $\frac{r(a+b+c)}{2}$ и формуле Герона) сумма сторон регулярно появляется вместе с множителем $\frac{1}{2}$.
3. Чтобы упростить запись таких выражений, вводится величина «полупериметр» $p$, определяемая как половина периметра:
   $$p = \frac{P}{2}.$$
4. Подставляя $P = a + b + c$, получаем развёрнутое определение:
   $$\boxed{p = \frac{a + b + c}{2}}.$$

**Почему сумма трёх сторон делится на два:** деление на $2$ является частью самого определения слова *полу*периметр ($\frac{1}{2}$ от полного периметра $a + b + c$), а на практике в формуле [`F-004`](F-004-area-incircle-radius.md) оно естественно возникает из фактора $\frac{1}{2}$ в площади треугольника $\frac{\text{основание}\times\text{высота}}{2}$.

## 11. Dependency Graph
- **Опирается на:** определение длин сторон $a, b, c$ и определение периметра $P = a + b + c$.
- **Является основанием для:** [`F-004`](F-004-area-incircle-radius.md) (преобразование $S = \frac{r(a+b+c)}{2} \to S = pr$) и [`F-005`](F-005-right-triangle-inradius.md).

## 12. Mathematical Status
- **Статус достоверности:** `DEFINITION` (определение введённой математической величины; не является теоремой или гипотезой — проверке подлежит только согласованность употребления символа $p$ и соблюдение неравенств треугольника).

## 13. Numerical Example
Контрольный прямоугольный треугольник $5\text{–}12\text{–}13$:
- Стороны: $a = 5$, $b = 12$, $c = 13$.
- Периметр (полная длина контура): $P = 5 + 12 + 13 = 30$.
- Полупериметр (половина периметра): $p = \frac{5 + 12 + 13}{2} = \frac{30}{2} = 15$.
- Проверка неравенств $p > a, b, c$: $15 > 5$, $15 > 12$, $15 > 13$ (треугольник невырожден).

## 14. Validation Cases
1. Треугольник $(3, 4, 5)$: $P = 12$, $p = \frac{3+4+5}{2} = 6$.
2. Треугольник $(5, 12, 13)$: $P = 30$, $p = \frac{5+12+13}{2} = 15$.
3. Равносторонний треугольник $(2, 2, 2)$: $P = 6$, $p = 3$.
4. Вырожденная тройка $(1, 2, 3)$: алгебраически $\frac{1+2+3}{2} = 3 = c$, но условие невырожденности $p > c$ нарушено ($3 \not> 3$).

## 15. Common Misinterpretations
1. **Подмена полупериметра периметром:** использование $P = a+b+c$ вместо $p = \frac{a+b+c}{2}$ в формуле $S = pr$ завышает площадь ровно в $2$ раза.
2. **Путаница $p$ (полупериметр) с $P$ (периметр) или $s$ / $S$ (площадь):** без таблицы символов однобуквенное обозначение $p$ или $s$ нечитаемо.
3. **Восприятие $p = \frac{a+b+c}{2}$ как теоремы:** это конвенциональное определение, не требующее доказательства.
