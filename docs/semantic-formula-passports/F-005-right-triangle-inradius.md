# F-005 — Радиус вписанной окружности прямоугольного треугольника (`Right-Triangle Inradius`)

## 1. Formula ID
`F-005` *(соотносится с `PCL-D12` в Pythagoras-Circles-Lab и используется в `PTH-004` в UMFP Insight Bank)*

## 2. Formula Name
Две эквивалентные формулы радиуса вписанной окружности прямоугольного треугольника (`Rational and Linear Inradius Formulas`)

## 3. Canonical Expression
**Рациональная (численно устойчивая) форма:**
$$r = \frac{ab}{a + b + c}$$
**Линейная форма (следствие теоремы Пифагора):**
$$r = \frac{a + b - c}{2}$$

## 4. Semantic Statement
Радиус окружности, вписанной в прямоугольный треугольник с катетами $a, b$ и гипотенузой $c$, равен отношению произведения катетов к периметру треугольника и в силу теоремы Пифагора тождественно равен половине разности между суммой катетов и гипотенузой.

|---|---|---|---|---|
| $r$ | Радиус вписанной окружности | Вычисляемая величина | Выражается из равенства двух формул площади треугольника (`F-002` и `F-004`) | $r \in \mathbb{R}_{>0}$ |

| $p$ | Полупериметр треугольника (вспом.) | Сокращённое обозначение | $p = \frac{a+b+c}{2}$ (`F-003`) | $p > c > 0$ |

## 6. Definitions
- **Прямоугольный треугольник:** невырожденный треугольник со сторонами $a, b, c > 0$, удовлетворяющими $a^2 + b^2 = c^2$ (`F-001`).
- **Вписанная окружность радиуса $r$:** см. [`F-004`](F-004-area-incircle-radius.md).
- **Численная аннигиляция (catastrophic cancellation):** потеря значащих цифр в арифметике с плавающей точкой при вычитании почти равных чисел (в формуле $\frac{a+b-c}{2}$, когда $a \ll b$, так что $c \approx b$).

## 7. Geometric Interpretation
Линейная формула $r = \frac{a + b - c}{2}$ имеет прямой геометрический смысл касательных отрезков:
1. В точке прямого угла $O$ два касательных отрезка от $O$ до точек касания $T_a$ на $OA$ и $T_b$ на $OB$ равны $r$ (образуют квадрат $r \times r$).
2. Оставшиеся части катетов равны $a - r$ и $b - r$.
3. По равенству отрезков касательных, проведённых к окружности из вершин $A$ и $B$, гипотенуза разбивается на два отрезка длиной $(a - r)$ и $(b - r)$:
   $$c = (a - r) + (b - r) = a + b - 2r \implies 2r = a + b - c \implies r = \frac{a + b - c}{2}.$$
Алгебраический вывод ниже показывает, как это же соотношение следует из формул площади и теоремы Пифагора.

## 8. Preconditions
1. Треугольник **прямоугольный** на евклидовой плоскости ($a^2 + b^2 = c^2$).
2. Все стороны строго положительны ($a, b, c > 0$).
3. Замечание о границах применимости:
   - формула $r = \frac{S}{p} = \frac{2S}{a+b+c}$ верна для любого треугольника;
   - формулы $r = \frac{ab}{a+b+c}$ и $r = \frac{a+b-c}{2}$ верны **только для прямоугольного треугольника** (первая использует $S = \frac{ab}{2}$, вторая — дополнительно $a^2+b^2=c^2$).

## 9. Domain and Constraints
- **Область определения:** $(a, b) \in (0, +\infty)^2$, $c = \sqrt{a^2 + b^2}$.
- **Положительность радиуса:** по строгому неравенству треугольника $a + b > \sqrt{a^2 + b^2} = c$, откуда $a + b - c > 0$ и $r > 0$.
- **Ограничения `UMFP Core 0.1.x`:**
  - `r = (a * b) / (a + b + c)` имеет ограничение `a + b + c != 0 [required]`;
  - `r = (a + b - c) / 2` имеет ограничение `2 != 0 [required]`;
  - без явного контекста `c^2 = a^2 + b^2` Core классифицирует оба выражения как `ALGEBRA` и не может автоматически доказать их эквивалентность только по AST.

## 10. Derivation
Выполним полный вывод в два этапа без единого пропущенного перехода:

### Этап A. Вывод рациональной формы $r = \frac{ab}{a+b+c}$
1. По формуле площади прямоугольного треугольника ([`F-002`](F-002-right-triangle-area.md)):
   $$S = \frac{ab}{2}.$$
2. По общей формуле площади через радиус вписанной окружности ([`F-004`](F-004-area-incircle-radius.md)) с раскрытым полупериметром $p = \frac{a+b+c}{2}$ ([`F-003`](F-003-semiperimeter.md)):
   $$S = pr = \frac{r(a + b + c)}{2}.$$
3. Поскольку обе формулы выражают площадь $S$ одного и того же треугольника, приравниваем правые части:
   $$\frac{r(a + b + c)}{2} = \frac{ab}{2}.$$
4. Умножаем обе части равенства на $2$:
   $$r(a + b + c) = ab.$$
5. Так как $a, b, c > 0$, сумма $a + b + c > 0$ строго не равна нулю. Делим на $(a + b + c)$:
   $$\boxed{r = \frac{ab}{a + b + c}}.$$

### Этап B. Переход к линейной форме $r = \frac{a+b-c}{2}$ через теорему Пифагора
6. Умножим числитель и знаменатель дроби $\frac{ab}{a + b + c}$ на сопряжённое выражение $(a + b - c)$. По строгому неравенству треугольника $a + b > c$, поэтому $a + b - c > 0$ (деление и умножение на ненулевую величину допустимо):
   $$r = \frac{ab\,(a + b - c)}{(a + b + c)(a + b - c)}.$$
7. Раскроем знаменатель по формуле разности квадратов $(X + Y)(X - Y) = X^2 - Y^2$, где $X = a + b$, $Y = c$:
   $$(a + b + c)(a + b - c) = (a + b)^2 - c^2.$$
8. Раскроем квадрат суммы $(a + b)^2 = a^2 + 2ab + b^2$:
   $$(a + b)^2 - c^2 = a^2 + 2ab + b^2 - c^2 = (a^2 + b^2 - c^2) + 2ab.$$
9. По теореме Пифагора ([`F-001`](F-001-pythagorean-theorem.md)) для прямоугольного треугольника $a^2 + b^2 = c^2$, поэтому $a^2 + b^2 - c^2 = 0$:
   $$(a + b + c)(a + b - c) = 0 + 2ab = 2ab.$$
10. Подставляем упрощённый знаменатель $2ab$ обратно в выражение для $r$:
    $$r = \frac{ab\,(a + b - c)}{2ab}.$$
11. Поскольку $a > 0$ и $b > 0$, произведение $ab > 0$ сокращается в числителе и знаменателе:
    $$\boxed{r = \frac{a + b - c}{2}}.$$

Таким образом, линейная формула $r = \frac{a+b-c}{2}$ является **прямым следствием** двух формул площади (`F-002`, `F-004`) и теоремы Пифагора (`F-001`).

## 11. Dependency Graph
- **Опирается на:** [`F-001`](F-001-pythagorean-theorem.md) ($a^2+b^2=c^2$), [`F-002`](F-002-right-triangle-area.md) ($S = \frac{ab}{2}$), [`F-003`](F-003-semiperimeter.md) ($p = \frac{a+b+c}{2}$), [`F-004`](F-004-area-incircle-radius.md) ($S = pr$).
- **Является основанием для:** [`F-006`](F-006-four-circles-identity.md) ($a + b = c + 2r \iff \sqrt{K_a}+\sqrt{K_b}=\sqrt{K_c}+\sqrt{K_i}$).

## 12. Mathematical Status
- **Статус достоверности:** `DERIVED` (строго доказанное следствие формулы площади и теоремы Пифагора).
- **Вычислительная рекомендация:** в программном коде (`src/math/FourCirclesModel.ts`) используется форма `(a / (a + b + c)) * b`, поскольку она избегает потери точности при вычитании $b - c$ в случае сильно вытянутых треугольников ($a \ll b$).

## 13. Numerical Example
Контрольный прямоугольный треугольник $5\text{–}12\text{–}13$ ($a = 5, b = 12, c = 13$):
1. Через площадь и полупериметр (`F-002`, `F-003`, `F-004`):
   $$S = \frac{5 \cdot 12}{2} = 30, \qquad p = \frac{5 + 12 + 13}{2} = 15 \implies r = \frac{S}{p} = \frac{30}{15} = 2.$$
2. Через рациональную формулу:
   $$r = \frac{5 \cdot 12}{5 + 12 + 13} = \frac{60}{30} = 2.$$
3. Через разность квадратов и теорему Пифагора:
   $$(5 + 12 + 13)(5 + 12 - 13) = 30 \cdot 4 = 120 = 2 \cdot 5 \cdot 12 = 2ab,$$
   $$r = \frac{5 + 12 - 13}{2} = \frac{4}{2} = 2.$$

## 14. Validation Cases
1. $(3, 4, 5)$: $r = \frac{12}{12} = 1$, линейная форма $\frac{3+4-5}{2} = 1$.
2. $(5, 12, 13)$: $r = \frac{60}{30} = 2$, линейная форма $\frac{5+12-13}{2} = 2$.
3. $(4, 4, 4\sqrt{2})$: $r = \frac{16}{8 + 4\sqrt{2}} = 4 - 2\sqrt{2} \approx 1.171573$.
4. Сильно вытянутый $(1, 10^5, \sqrt{1 + 10^{10}})$: рациональная форма $\frac{10^5}{1 + 10^5 + c}$ устойчиво даёт $r \approx 0.4999975$, тогда как прямая $(a+b-c)/2$ в `float64` теряет значащие разряды.

## 15. Common Misinterpretations
1. **Применение $r = \frac{a+b-c}{2}$ к произвольному треугольнику:** для треугольника с углом $\gamma \neq 90^\circ$ величина $\frac{a+b-c}{2}$ **не равна** вписанному радиусу (исключено условие $a^2+b^2=c^2$).
2. **Отождествление $r$ (вписанный радиус $K_i$) и $R_o = c/2$ (описанный радиус Фалеса):** это разные окружности ($r < R_o$ всегда).
3. **Замена $(a+b-c)/2$ на $(a+b+c)/2$:** знак «$-$» перед гипотенузой возникает из $c = (a-r)+(b-r)$, а $(a+b+c)/2$ — это полупериметр $p$.
