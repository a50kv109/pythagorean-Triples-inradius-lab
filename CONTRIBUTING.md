# Contributing — Pythagoras Four Circles Laboratory (PCL)

Благодарим за интерес к внесению вклада в развитие проекта «Пифагор — Лаборатория четырёх кругов»!

## Руководящие принципы

1. **Математическая строгость превыше всего:** Любое изменение математического ядра требует предварительного аналитического обоснования и обновления паспортов формул UMFP (`PCL-*` в `docs/FORMULA_PASSPORTS.md`) и матрицы верификации (`docs/VERIFICATION_MATRIX.md`).
2. **Изоляция ядра:** Математические модули (`src/math/*`) должны оставаться чистыми функциями без сайд-эффектов и без зависимостей от пользовательского интерфейса или React.
3. **Тестирование:** Все изменения должны проходить существующие тесты (`npm test`), проверку типов (`npm run lint`) и сохранять точность с допуском $\le 10^{-9}$.
4. **Лицензирование:** Внося вклад, вы соглашаетесь на распространение ваших изменений под лицензией **MIT License** (`LICENSE`) с сохранением заголовка `SPDX-License-Identifier: MIT`.

## Процесс внесения изменений

1. Создайте ветку для вашей задачи (`git checkout -b feature/my-enhancement`).
2. Внесите изменения в математическое ядро или компоненты визуализации.
3. Добавьте юнит-тесты в `src/tests/geometry.test.ts`.
4. Запустите проверки:
   ```bash
   bun install --frozen-lockfile
   npm test
   npm run lint
   npm run build
   ```
5. Убедитесь, что все тесты проходят успешно, UI-строки добавлены во все три локали (`ru`, `uk`, `en` в `src/i18n/translations.ts`), и создайте Pull Request.
